【搜索指令】
用户想了解是否存在现成项目/轮子可以二开，避免重复造轮子。你必须：
1. 在 GitHub 搜索相关项目（中英文多组关键词，按 star 排序）
2. 关注：star 数、最近更新时间、issue 活跃度、license 类型、commit 频率
3. 如果找到候选项目，搜索该项目的深度评测、对比文章、社区评价
4. 如果没找到直接匹配，搜索相近领域项目看能否改造
5. 评估候选项目的架构质量：分层是否清晰、模块耦合度、扩展性

【输出约束】
- 用中文回答
- 先给结论：有/没有直接可用的项目，能否二开，推荐基于哪个项目
- 列出现有项目，每个给出：star 数、最近更新时间、核心功能、架构质量评估、匹配度（1-5星）
- 给出二开方案：基于哪个项目改、架构需要调整哪些部分、预估工作量、风险点
- 如果都不合适，给出"建议从头造"的理由和最小可行架构思路
- 不要写代码，用架构名称、模块职责说明方案
- 禁止客套话和泛泛而谈
- 所有项目必须附上 GitHub 链接，文章附原文 URL
