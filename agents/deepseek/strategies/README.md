# 策略模板

## 使用方式
在 goal.txt 的 constraints 中引用策略文件名，脚本会自动注入对应策略。

## 可用策略

### adversarial_review.txt
对方案进行对抗式审查，模拟攻击者/恶意用户/极端场景。
适用：安全相关、权限设计、架构决策。

### project_research.txt
调研项目相关的技术选型、最佳实践、竞品方案。
适用：技术选型、架构设计、新领域探索。

### recommend.txt
基于现有约束给出推荐方案，说明理由和权衡。
适用：多方案对比、决策困难时。

### search_and_review.txt
搜索并审查多个来源，交叉验证信息。
适用：事实核查、技术细节确认。
